# GsMumbo MCP · Public organization profile

This repository owns the **public** GitHub organization homepage for [GsMumbo-MCP](https://github.com/GsMumbo-MCP).

- **[Open the profile content](profile/README.md):** Markdown displayed on the organization's Overview page for visitors.
- **[View the hero artwork](profile/assets/gs-mcp-hero.svg):** Custom organization banner.

This page is intentionally safe to share. Private repositories, internal service inventories, capability URLs, credentials, and operational topology do not belong in the public profile.

The member-only organization profile lives in a separate private `.github-private` repository and is visible only to authorized organization members.
